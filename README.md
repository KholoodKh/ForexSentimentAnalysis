# 🌍 ForexSentiment — AI-Powered Forex Market Analysis

💱 **Can AI understand the impact of financial news on currency markets?**

An NLP research project exploring the connection between 📰 financial news sentiment and 📈 Forex market movements, with a special focus on EUR/USD.

🤖 **What’s inside?**
- 🧠 GPT-powered financial news sentiment analysis
- 🔍 Prompt engineering and experimentation
- 📊 Sentiment classification with FinBERT & Longformer
- 🎯 Confidence-based classification and score refinement
- 💹 Analysis across multiple currency pairs
- 📉 Evaluation using accuracy and confusion matrices

🚀 **Goal:** Explore how AI can turn financial news into meaningful signals for Forex market prediction.

**Built with:** Python · GPT · NLP · Transformers · Pandas · NumPy
