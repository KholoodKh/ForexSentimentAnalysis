# 💱 ForexSentiment — Reproduction and Improvement of a Forex News Sentiment Analysis Approach

📊 **Reproducing and improving a research-based approach to financial news sentiment analysis using GPT and pretrained language models.**

## 🌍 Overview

ForexSentiment is an experimental NLP project based on the implementation of an existing research paper on financial news sentiment analysis for Forex markets. The project reproduces the original approach and investigates ways to improve its sentiment-classification performance, particularly when analyzing financial news related to currency movements.

The work focuses on refining GPT prompts, improving input formulation, and applying confidence-based correction to classification outputs. The resulting approach is evaluated against pretrained financial language models, including FinBERT and Longformer.

## ✨ Key Contributions

- 📄 **Research Reproduction:** Reimplemented the methodology of an existing paper for financial news sentiment analysis in the Forex domain.
- 🤖 **GPT Prompt Refinement:** Experimented with different prompt formulations and input structures to improve financial sentiment classification.
- ⚙️ **Confidence-Based Correction:** Introduced a confidence-based correction strategy to refine classification predictions.
- 🧠 **Model Comparison:** Compared the GPT-based approach with FinBERT and Longformer.
- 📊 **Performance Evaluation:** Analyzed classification accuracy and confusion matrices to investigate prediction quality and class-specific errors.
- 💹 **Forex Data Analysis:** Examined financial news sentiment in the context of Forex currency movements, including EUR/USD.

## 📈 Results

Improved the GPT-based classification accuracy from **75% to 77%** through prompt refinement and confidence-based correction, alongside a comparative evaluation of sentiment-classification approaches.
